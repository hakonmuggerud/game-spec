# Parity fixtures

Generated by `tools/export/export.mjs` from the prototype's own `maps.js` (never by hand); the Rust ports in
`crates/undercroft-sim` must reproduce every number here. Regenerate with:

```sh
cd undercroft/tools/export && npm install && node export.mjs
```

Grid conventions (DESIGN.md §3): `idx = cz * w + cx`, row 0 = north, cell `(cx, cz)` spans
`x ∈ [ox+cx, ox+cx+1)`, `z ∈ [cz, cz+1)`; a cell's centre is `(ox + cx + 0.5, cz + 0.5)`.

## `<map>.json` — `undercroft`, `cistern`, `ossuary`, `source`, `hub`, `hub_v1`

One file per zone (`maps.parseZone(id)`), the v2 hub (`maps.parseHub()`, `ox` 60) and the legacy v1 hub
(`parseHub(HUB_ROWS)`, its `rows` embedded since it has no map file).

| Field | Meaning |
|---|---|
| `id`, `w`, `h`, `ox` | map id and grid size / world x offset |
| `entry` | `[cx, cz]` of the `S` / `V` cell — the start of every BFS below |
| `cells` | `w*h` cell kinds as `maps.T` numbers (floor 0, wall 1, pillar 2, deep 3, stairs 4, water 5, gate 6, elevator 7, altar 8, shortcut 9) |
| `counts` | cells per kind name (`T_NAME`) |
| `walkable` | cells that are not `isSolid` (wall / pillar / gate / shortcut). NB: `validate_all.json`'s `stats.walkable` counts non-`#`/`P` chars instead, so it is larger by the gate + shortcut count |
| `bfs_dist`, `bfs_parent` | `bfsField(m, entry)` with the default predicate (`isBlocked` over an empty pool = `isSolid`): `Int16` distances (−1 unreachable) and `Int32` parents (−1 for the start / unreachable). Parents depend on the neighbour order `[1,0] [-1,0] [0,1] [0,-1]` |
| `paths[]` | `pathTo` probes: `{from, to, target:[cx,cz], cells:[[cx,cz]…]}`. `from` is `entry` (the field above) or an anchor path (a fresh `bfsField` from that anchor); `cells` are the path's cells in order, start cell excluded (the JS returns centres; `floor(x − ox), floor(z)` here) |
| `los[]` | `los` probes: `{from, to, a:[x,z], b:[x,z], ab, ba}` — world points and the result in both directions. Anchor centres, plus off-centre probes (names suffixed `+`, points at `+0.13/+0.87` and `+0.71/+0.29` inside the cell) |
| `nearest[]` | `nearestReachable(field, at)` probes on the entry field: `{at:[x,z], idx}` (−1 = nothing reachable) |
| `laps` | Source only: `lapOf(cx, cz, m)` for every cell (`w*h` ints; −1 on the border ring) |
| `route` | `routeCells(m, opts)` for `closed` (`gatesOpen` true, `scOpen` false), `open` (both true) and `gates_closed` (both false): `{cells, unreachable}` |
| `markers` | the parser's marker lists: `items[] {kind, cx, cz}`, `stairs`, `hunter_spawns[]`, `npc_cells[]`, `spots[] (+id)`, `gates[] (+id, open)`, `shortcuts[] (+id, name, openFrom, from, to, saves, cells, open)`, `flame`, `anchors {digit: marker}`, `altar`, `creatures[] (+kind)` — every marker is `{cx, cz, idx, x, z}` with the world centre |

Anchor names in `paths` / `los` are flattened `ANCHORS` paths (`entry`, `gateFar`, `shortcuts.u_rood`,
`hunters[1]`); the hub uses `entry`, `flame` and `anchor1`…`anchor7`.

## `lap_legacy.json`

`lapOf(cx, cz)` with no map: the legacy 40×40 / band 3 / maxLap 5 spiral, `laps` row-major.

## `validate_all.json`

The complete `maps.validateAll()` result: `{ok, errors[], warnings[], zones: {id: result}, hub, hubV2}`, each
result `{ok, errors, warnings, stats}`. `stats` carries the char counts (`S V A H N C X W o r R D P F = L G Y B w`;
NB `w` is the Drowner char count, the grid size is `width`/`height`), `walkable`, `walls`, `wallShare`,
`reachable`, `gatedCells`, `shortcutOnlyCells`, `behindGate[]`, `shortcuts[] {id, name, cells, openFrom, saves,
detour, dBarred, dOpen}`, `route {closed, open}` and, for the Source, `altarLap`, `creatureLaps[]`, `hunterLaps[]`.
The committed maps validate with zero errors and zero warnings; the validator port must reproduce the stats.
