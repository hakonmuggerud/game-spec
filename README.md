# The Undercroft

A lamp-lit dungeon crawler about a light economy, in development.

- [`undercroft/`](undercroft/) — **the game**: a Rust + Bevy workspace, native and web. Its
  [README](undercroft/README.md) has the build, test and run recipes; its
  [DESIGN.md](undercroft/DESIGN.md) is the design as implemented, and `undercroft/assets/data/`
  holds every game number.
- [`spec.md`](spec.md) — the original concept document, plus two market reports
  (`game-trends-fit-report.md`, `market-saturation-report.md`).
- [`reference/`](reference/) — history: the Three.js prototype the port was verified against
  (still runnable in a browser, see its [README](reference/README.md)) and the tools that
  extracted its data. Frozen; nothing there is edited any more.
